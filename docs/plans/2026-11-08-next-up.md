## 1. Now, while the databases are empty

Both databases were wiped on 2026-11-08, so schema changes need no data migration.

1. **Schema fixes from the database review.** The main one is `receipts.receipt_date` from text to `date`. In progress.
2. **Default OCR chain.** Decided 2026-11-08: Claude Haiku 5.5, then Gemini Flash-Lite, then Qwen on Groq, in that
   fixed order. A random fallback order was considered and rejected: a fallback runs only when the step before it
   fails, so randomizing saves nothing and makes failures and benchmarks harder to explain. In progress.
