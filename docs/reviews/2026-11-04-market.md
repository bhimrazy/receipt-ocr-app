Pattern: API vendors sell per document at $0.04-0.16 (tiers $28-500/mo); hyperscalers ~$0.01;
app vendors sell seats at $3-38/mo. Free tiers are tiny (2-100 docs/mo). Nobody I could verify
sells "bring your own LLM key". I did not find a verified LLM-native receipt app with real traction;
this is an absence in search results, not proof.

## 2. Where an LLM-native (Gemini) app can win

Accuracy evidence is thin. The only receipt number found is a 2024 vendor eval (Gemini 1.5 Flash ~87.7%
factuality, [Braintrust](https://braintrust.dev/blog/gemini)); a 2025 benchmark incl. SROIE exists
([arXiv 2509.04469](https://arxiv.org/pdf/2509.04469)) but results were not read. Generic claims that
LLMs beat OCR on varied layouts ([RaftLabs](https://www.raftlabs.com/blog/ocr-vs-llm-invoice-processing)) are vendor opinion.
Run our own benchmark before claiming accuracy.

| Segment | Fit | Why |
|---|---|---|
| Developers via API | Strong | Veryfi's floor is $500/mo, Taggun $28 for 500 scans, Mindee has no free plan. A free-100 + $0.01-0.02/receipt API with schema-typed JSON undercuts all three. Needs API keys, docs, webhooks (none exist today). |
| Freelancers / sole traders | Strong, seasonal | QuickBooks free allows 2 uploads; Expensify free ~25. Want export + category + tax fields, not approvals. |
| Small accounting practices | Medium | Dext owns this (client portals, bank feeds, practice tiers). Win only with bulk upload + QuickBooks/Xero export + cheap per-client pricing. Slow sales cycle. |
| Small businesses / teams | Weak now | Expensify/Zoho/Ramp give approvals, cards, reimbursement for $0-5/user. We lack all of it. |
| South Asia (India/Nepal) | Promising, unproven | Zoho dominates India. GST invoices (GSTIN, CGST/SGST/IGST split) and Tally export are unserved gaps for a lightweight tool. Nepal: searches returned nothing usable (VAT/PAN bill, Nepali-script, NPR); needs primary research with real users. Multilingual handwriting/vernacular receipts is where an LLM beats template OCR. |

## 3. Pricing recommendation

### Gemini cost (the constraint)

Official page ([aistudio.google.com/docs/pricing](https://aistudio.google.com/docs/pricing), fetched via summarizer, no page date) lists per 1M tokens:
`gemini-3.8-flash` / `3.6-flash` $0.75 in, $3.75 out through 2026-12-31, **$1.50 / $7.50 from 2027-01-01**;
`3-flash-preview` $0.50/$3.00; `3.1-flash-lite` $0.25/$1.50; `3.5-flash-lite` $0.30/$2.50;
`2.5-flash-lite` $0.10/$0.40; `2.5-flash` deprecated, rerouted 2026-12-01. Batch = 50% off.
Verify on the live page: the code uses `gemini-3.7-flash` (`packages/ai/src/index.ts:76`), which the summary did not list.

My estimate per receipt (assumption: ~2,000 input tokens incl. image and prompt, ~600 output tokens, thinking excluded):

| Model | Now | From 2027-01-01 |
|---|---|---|
| 3.x Flash | ~$0.004 | ~$0.0075 |
| 3.1 Flash-Lite | ~$0.0014 | same |
| Flash via Batch | half of Flash | half of Flash |

Thinking tokens bill as output and can double it; measure real usage from logs before setting prices.

### Current limits are the problem

`apps/web/lib/plans.ts`: free = **50 receipts/day**, pro = 1,000/day. A free user at the cap costs
about 1,500 x $0.004 = **~$6/mo (~$11 after Jan 1)** on managed keys, with no revenue.
Bot or multi-account abuse is uncapped per org.

### Proposal

| Plan | Price | Limits | Notes |
|---|---|---|---|
| Free | $0 | 25 receipts/mo (rolling), 1 workspace, CSV/JSON, no card | Matches Expensify free; cost <= $0.20/user. Use Flash-Lite for free tier if accuracy holds on benchmark. |
| Solo | $6/mo ($5 annual) | 300/mo, bulk upload, email-in, duplicate detection, categories, Sheets/Excel | Cost ~$1.20-2.30 -> 60-80% margin. Undercuts SimplyWise/Shoeboxed ($29). |
| Pro | $15/mo | 1,500/mo, QuickBooks/Xero export, 5 workspaces, API access | Cost ~$6-11 worst case; most users use far less. Overage $0.02/receipt. |
| API (dev) | Free 100/mo, then $0.015/receipt, no minimum | Pay-as-you-go, 60 rpm | ~4x cost margin, 5x under Veryfi $0.08, ~3x under Taggun. |
| BYOK | $5/mo flat | Unlimited on user's key | Only after BYOK ships (see `docs/byok-key-management.md`, status: design only). |
| Teams/Practice | Per-client or per-seat, quote | Later | Don't build before 20 paying users. |

Rationale: the CEO review's $9-15 Pro and $0.005-0.01 API sit near or below cost once Flash prices double
in January; $0.015 keeps margin. Re-run this table after measuring token usage.

## 5. Top insights

1. API incumbents price high: Veryfi $0.08/receipt with $500/mo floor; Taggun $0.04-0.06. A $0.015 pay-as-you-go API is a real gap.
2. App-side free tiers are tiny (QuickBooks 2, Expensify ~25, Scanomy 10), so a 25/mo free plan is competitive and affordable.
3. Current 50/day free cap costs ~$6-11/user/mo and Flash prices double on 2027-01-01.
4. The BYOK headline is not shipped and the "100%" stat is indefensible: fix or remove before any launch.
5. Missing table stakes block the bookkeeper claim: QuickBooks/Xero export, PDF, duplicates, email-in, GST/VAT fields.

## 6. Changes to make

1. Pick developers (API) first, freelancers second; drop "Bookkeepers" and "Small teams" cards until integrations exist.
2. Publish prices (Free 25/mo, Solo $6, Pro $15, API $0.015) and cut the free cap in `plans.ts` to monthly.
3. Replace unsupported claims (100%, BYOK-as-shipped, "ledger", "No lock-in") with a measured benchmark, a curl example, and "BYOK coming" until shipped.
