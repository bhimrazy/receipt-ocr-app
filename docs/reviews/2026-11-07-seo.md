Checks run with the SearchFit skills `seo-audit` (crawlability, meta, headings, images, structured data, performance),
`schema-markup` (JSON-LD shape and rules: absolute URLs, no empty values, no invented data) and `ai-visibility`
(llms.txt, crawlability by AI bots, factual structured content). The `ai-visibility` prompt-testing half (asking
assistants about the brand) was not run: it needs live assistants.

Hard rule from the owner: only `https://receipt-ocr.bhimraj.com.np` is indexable. Every other host (preview deployments,
`preview.receipt-ocr.bhimraj.com.np`, `preview-receipt-ocr.vercel.app`, `receiptocr.vercel.app`, localhost) serves
`Disallow: /`, sends `X-Robots-Tag: noindex, nofollow` and has no `llms.txt`.

## Checked and fine

- Lab routes (`(lab)`): 404 in production (`LAB_PAGES` unset), `noindex` metadata, not in the sitemap, `Disallow: /landing-` and `/final-`.
- 404 page: `robots: noindex`, real 404 status.
- Titles and descriptions: unique per public page, 50 to 160 characters (asserted in `e2e/seo.spec.ts`); one `<h1>` per page.
- Open Graph and Twitter cards on every page via `pageMetadata`; `/opengraph-image` is a 1200x630 PNG.
- Canonicals are absolute through `metadataBase`, no query strings; `/privacy/` 308s to `/privacy`.
- HTTP to HTTPS: `http://receipt-ocr.bhimraj.com.np/` returns 308 to https; HSTS is set.
- `receiptocr.vercel.app` returns 308 to the production host.
- hreflang: not needed. One language (`en`), one region-neutral site.
- Manifest: `name` and `short_name` are `receiptOCR`, matching `applicationName` and the Apple title.
- Image alt text: the public pages use no `<img>`; the in-app images have `alt` (decorative ones `alt=""`).
- Core Web Vitals, from code only: fonts use `display: swap` with next/font; the landing page is statically prerendered. Not measured.

## Trade-off to know

`/sign-in`, `/sign-up` and `/forgot-password` are not disallowed: they are linked from public pages, and a disallowed
URL can still be listed as a bare result because Google never reads its `noindex`. Crawlable, they are fetched, the
`noindex` header and meta tag are read, and they drop out. Token-bearing and signed-in paths stay disallowed.
