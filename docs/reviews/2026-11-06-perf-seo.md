## Fixed

- Hero and preview use a transform-only entrance (`animate-rise`), so the hero text paints at once and is the LCP
  element. Observed home FCP 1451 ms to 223 ms.
- Support widget: launcher only on page load; the form, its fields and Turnstile load with `React.lazy` on first open
  (warmed on hover or focus). A draft survives closing.
- FAQ uses native `details`/`summary`: no client JS and every answer is in the HTML.
- SiteHeader and ContactButton resolve button classes on the server; the client islands no longer ship cva,
  tailwind-merge or the Base UI Button.
- Hero floating receipts are server-rendered; only the pointer parallax is a client island.
- Per-page titles, descriptions (50 to 160 chars), canonical, og:url, og:title and Twitter tags via `pageMetadata` in
  `lib/seo.ts`. Before, every page inherited the home page's og:title, og:url and description.
- OG images: privacy and terms have their own; other pages name the root card explicitly (a page-level `openGraph`
  drops the inherited file image).
- JSON-LD on home: Organization, WebSite, SoftwareApplication (free plan offer only, no ratings or reviews) next to the
  existing FAQPage, which matches the visible FAQ.
- robots.txt blocks only `/api/` and the lab prefixes. `/app`, `/admin` and the auth flows are crawlable so crawlers
  can see their noindex; `X-Robots-Tag: noindex` is now also sent on those paths (including the signed-out redirect).
- Sitemap has `lastModified` for the legal pages, from the same dates the pages print.
- A11y: heading-order (product preview h3 after h1), link-in-text-block (sign-up terms links now underlined).
- CI guard: `e2e/seo.spec.ts`.

## Follow-ups for other tracks (not edited here)

- Root layout (PWA track): DM Sans with the `opsz` axis (62 KB) and JetBrains Mono (40 KB) are preloaded on every
  page; consider `preload: false` for mono or dropping the axis. Root `openGraph.url: "/"` and the 179-char
  `siteDescription` are still inherited by pages without their own metadata (404, invitation, /app).
- /app/history (mobile shell track): simulated LCP 4.1 s (observed 388 ms vs FCP 92 ms). The LCP element is the search
  box placeholder, which paints only after the toolbar's JS runs.
- /app/receipts/[id] (mobile shell track): simulated LCP 4.1 s; the LCP element is the receipt image (634 ms render
  delay). The `<img>` has no width and height. A11y: `dl` wraps `dt`/`dd` in extra divs (definition-list, dlitem).
