# Product review — 2026-11-04

_Scope: code-only read of `apps/web` (landing, auth, upload, receipt, history, settings, members,
admin) and `packages/email`, on branch `feat/better-auth-workspaces-admin`. No app run; visual
critique is a separate pass._

## Verdict

The core loop works and is short: sign up, drop a photo, get an editable receipt, export CSV.
Since July the team shipped real correctness work (edit, delete, export, email, quotas, account
deletion). But the **marketing still sells features that don't exist** (bring-your-own-keys,
per-field confidence, "100% of line items"), the **in-app usage meter is a hard-coded fake**, and
the build went into **teams/workspaces/admin** before the jobs a paying freelancer needs
(PDF upload, date-range totals, full-history search). Before charging anyone: make every claim
true or remove it, then build "tax-time export". Leave teams, BYOK and integrations for later.

## 2. First-run experience (beginner)

Happy path: **Landing → Get started free → 3 fields → Create account → /app/upload → pick file →
choose "Process now" or "Queue in background" → wait → receipt page.** That's 4 clicks and 3
fields, which is good. Friction and dead ends:

1. **Fake usage meter.** The sidebar always says "Free tier 23 /50 this month"
   (`app/app/layout.tsx:52-58`). It's hard-coded, says "month" when the real limit is per day
   (`lib/plans.ts:17`), and a brand-new user sees 23 used.
2. **A mode choice before the first value.** One file shows "Process now" plus "Queue in
   background" (`upload-panel.tsx:300-317`). A beginner can't know which to pick. Default to
   process now and only show queueing for 2+ files.
3. **No sample receipt.** The first moment depends on having a receipt on hand and is gated
   behind sign-up. Add "Try a sample receipt" on the empty dropzone, which also serves as the demo.
4. **Mobile users can't reach History.** The mobile header has only brand, switcher and user
   menu (`app/app/layout.tsx:64-70`), and the user menu has only Settings and Sign out
   (`user-menu.tsx:84-102`). A PWA pitched on phone capture needs a bottom tab bar.
5. **Workspace concept shown to solo users.** On day one, "Bhim's Workspace" plus a switcher
   (`lib/auth.ts:36-38`, `app/app/layout.tsx:37`) with a locked "Upgrade to add workspaces" that
   leads nowhere (`workspace-switcher.tsx:196`). Hide the switcher until a user has 2+ workspaces.
6. **Receipt page has no next step.** The only nav is "Back to history" (`receipt-result.tsx:19-23`).
   After the first receipt, the obvious next action, "Upload another", is missing.
7. **Failure is a dead end.** "Extraction failed: Gemini OCR extraction failed. Try re-uploading"
   (`receipt-result.tsx:35-36` + `packages/core/src/index.ts:254`). That names the vendor, says no
   why, and has no retry button. The failed row also still counts toward quota (`lib/quota.ts:39`
   counts every row).
8. **Raw JSON dumped on every receipt** (`receipt-result.tsx:103-105`). Fine for developers,
   noise for everyone else. Collapse it behind a "Show JSON" toggle.
9. **Verification email sent silently** (`lib/auth.ts:63`). The app never mentions it, so it
   looks like spam. Either say "Check your inbox to confirm" or don't send it on sign-up.
10. **Queued batch lands on a stale History page.** Rows sit at "processing" until a manual
    refresh. Add the poller to History.
11. Auth panel footer shows the tech stack to consumers: "Next.js · Better Auth · Effect · AI SDK ·
    Drizzle" (`auth-layout.tsx:64`, also `site-footer.tsx:64`).

## 7. Plans, quotas, workspaces: can a user understand it?

No. A user sees three different numbers: the sidebar's fake "/50 this month", Settings'
"50 per day · 10 per minute (burst)" (`settings/page.tsx:43-48`), and a landing page with no
numbers at all. Hidden rules:
- Quota is **per user**, not per workspace (`quota.ts:39`), yet Settings shows it next to
  workspace info. In a team, each member has their own 50.
- Failed receipts count against the quota.
- "Pro" exists in code with no way to get it. "Upgrade" appears with no upgrade path.
- "Workspaces owned 1/1" is shown to people who will never need a second.

Proposal: one sentence, shown in three places (pricing card, sidebar, Settings):
**"Free plan: 50 receipts a day, 1 workspace."** Drop "per minute (burst)" from the UI (keep it
as an internal guard). Exclude failed receipts from the count. Hide workspace UI for solo users.
