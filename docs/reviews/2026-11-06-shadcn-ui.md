Registry classes like `dark:bg-input/30` thus always apply; fine today, but it means a future light theme requires reworking every primitive and the design-tokens test cannot catch it. State the dark-only decision in components.json docs/README; no `.dark {}` block exists, which is what shadcn CLI expects when it writes new tokens (`shadcn add` of a block that adds `.dark` vars will land in :root? check after next add).
   - No `--chart-*`, `--sidebar-foreground/primary/accent/border/ring` tokens (only `--sidebar`), so registry `sidebar`/`chart` items would be unstyled. Add when the usage charts land (usage design wants series colours; daily-chart.tsx should read `--chart-1..5`).
   - `--destructive` is the text-weight red (#f87171) and also the button background, with `--destructive-foreground` dark; `Alert` destructive uses `text-destructive` on `bg-destructive/10` (fine, ~7:1). Contrast spot calcs: muted-foreground #9a9aa3 on #0a0a0b ~7:1 and on --card #141416 ~6.4:1; --input #6b6b74 border on #0a0a0b ~3.7:1 (passes 1.4.11); primary #34d399 on bg ~11:1; warning on warning/10 fine. No failures found analytically; confirm `text-muted-foreground` on `bg-muted`/`bg-secondary` (#1c1c20 ~5.8:1) and disabled states (opacity-50 exempt).

   - globals.css: `.text-gradient`, `.card-sheen`, `.scan-line`, `.hero-aurora`, `.glow-orb`, `.floating-receipt`, `.animate-fade-up`, `.receipt-grid`, `.grid-mask` are landing/lab only (apps/web/app/globals.css:1-172) - the animated ones are correctly gated by `prefers-reduced-motion: no-preference` EXCEPT `.animate-fade-up` (globals.css bottom) which always runs. - Reduced motion handled for overlays (tw-animate-css override), button hover lift, and all landing animations except `.animate-fade-up`.
- Forms: EmailField sets autocomplete/inputMode/spellCheck; password `autoComplete="new-password"`; icons `aria-hidden`; `FocusHeading` for error-state focus; `aria-current="page"` in nav; `aria-live` on upload status; URL-driven filters/pager with real links (no `onClick` navigation, no click handlers on div/span found).

- `@source "./components"` solves Tailwind v4 monorepo scanning; `data-slot` on every primitive keeps shadcn-style overrides possible.
