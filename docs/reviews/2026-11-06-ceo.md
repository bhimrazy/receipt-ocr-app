## 2. Verdicts on the owner's ideas

**Per-receipt AI usage (tokens, cost).** Build it, for admins only. `extractReceipt` already returns usage
(`packages/ai/src/extract.ts:120-125`) but it is only written to the log event (`api/receipts/route.ts:132`), never
stored. Store `input_tokens`, `output_tokens`, `cost_usd_micros` and attempts on each receipt (one migration). Show
cost per receipt, per user, per day and per model on `/admin`. This is how you set prices and spot abuse.
**Customers should not see tokens or cost.** A freelancer doesn't think in tokens. A cost number invites "why did
this one cost more?" and anchors them on $0.004 when you charge per month. Show them **receipts used / remaining
(already built), and per receipt: confidence and which fields to check.** Put the model name in a details line, not
as a headline. Exception: when BYOK or an API plan ships, those users pay the provider bill, so show them their usage.

**Many models across providers.** An internal cost and quality lever, not a customer feature. A model picker asks a
bookkeeper a question they cannot answer and multiplies support. The admin chain (`core/src/ocr.ts`, `settings.ts`)
is the right shape. Add **one** second provider for fallback and price comparison (Anthropic Haiku or OpenAI small),
chosen by benchmark. Do not add "most widely used models": every model is an allowlist entry, a price row, a prompt
check and a bench run. One customer-facing version is worth testing later: **"Re-read with high accuracy"** on a
low-confidence receipt, which re-runs it on a stronger model. That turns the chain into visible value.

**PostHog / Sentry / Axiom.** Yes to PostHog (product funnel) and Sentry (errors), both behind env keys and off when
unset (matches the "optional locally" standard). Axiom: defer. The wide events already go to stdout/Vercel logs, and
receipts plus the new usage columns in Postgres answer cost questions with SQL. Add Axiom only when log retention hurts.

**"Make it a better product."** See the roadmap. The order follows one rule: **things that let someone pay, then
things that make paying users stay.**

## 4. Pricing and unit economics

**Model prices, per 1M tokens (fetched 2026-11-06):** Gemini 3.8 Flash $0.75 in / $3.75 out **until 2026-12-31,
then $1.50 / $7.50**; 3.1 Flash-Lite $0.25 / $1.50; 3.5 Flash-Lite $0.30 / $2.50; batch 50% off
([Google AI Studio pricing](https://aistudio.google.com/docs/pricing)). Claude Haiku 5.5 $0.10 / $0.50, Sonnet 5.5
$2 / $10 ([claude.com/pricing](https://claude.com/pricing)). OpenAI small tiers, third-party only and conflicting:
GPT-5.4 mini $0.75 / $4.50, nano $0.20 / $1.25 ([mem0](https://mem0.ai/library/llms-and-models/openai-api-pricing),
[BenchLM](https://benchlm.ai/openai/api-pricing), Nov 2026). Mistral OCR 4 ~$4 per 1,000 pages (3P,
[UsagePricing](https://www.usagepricing.com/blueprint/activity/mistral-ai-2026-07-06-api-rate-increase), Jul 2026).

**Risk: the production model `gemini-3.7-flash` (`packages/ai/src/models.ts`) is not on Google's price page**, and a
Google docs page says it now routes to 3.8 Flash ([Gemini 3.7 Flash docs](https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash),
2026-11-06). Assume 3.8 Flash pricing, and confirm before January.

**Per-receipt estimate (assumption, not measured):** light = 1.6k input / 0.6k output; heavy = 2k input / 3k output
including thinking tokens, which bill as output. A multi-page PDF multiplies input. A fallback adds a second call.

| Model | Light | Heavy |
|---|---|---|
| 3.8 Flash, now | $0.0035 | $0.013 |
| 3.8 Flash, from 2027-01-01 | $0.0069 | $0.026 |
| 3.1 Flash-Lite | $0.0013 | $0.005 |
| Haiku 5.5 (if accuracy holds) | ~$0.0005 | ~$0.002 |

**What this means for limits.** Free at 20/day = up to 600/month: **$4–15 per maxed free user per month from
January**, with no revenue. Pro at 1,000/day = 30,000/month: **$200–770 worst case**, with no price set. Daily limits
let one user consume a month's budget in any month. Move to **monthly** limits.

**Market anchors (fetched 2026-11-06):** SparkReceipt $6.90/mo for 50 docs, $12.90 unlimited
([sparkreceipt.com/pricing](https://sparkreceipt.com/pricing/)). Dext $25.21/mo for 250 docs and 5 users, line items
extra ([dext.com](https://www.dext.com/us/pricing/prepare-direct/)). Taggun API $28/500 to $799/20,000 scans
($0.04–0.06) ([taggun.io/pricing](https://www.taggun.io/pricing)).

**Proposal:** Free **30/month** on the cheapest model that passes the benchmark (target under $0.20 per user per month). **Pro
$9/mo or $90/yr, 500/month**; Flash cost at the heavy 2027 rate is under $13 worst case and ~$3.50 typical, and
SparkReceipt's $6.90 for 50 shows the price is acceptable. **Business $29/mo, 2,500/month, 5 members** (the seat
question). Overage packs rather than unlimited. Re-set all of this after 2 weeks of stored usage data.

## 6. PostHog: events and funnels

Events (server-side where possible, `workspace_id` as a group): `signed_up` (method), `email_verified`,
`receipt_uploaded` (source: picker/camera/drop/email, media type, pages), `receipt_completed` (ms, model,
confidence, item count, attempts, fallback_used), `receipt_failed` (kind), `receipt_retried`, `receipt_viewed`,
`receipt_field_edited` (field, low-confidence?), `receipt_reviewed` (fields changed count, seconds on page),
`export_downloaded` (format, row count, filtered?), `limit_reached`, `upgrade_clicked`, `checkout_started`,
`subscription_started`, `member_invited`, `invite_accepted`.

Funnels to watch weekly:
1. **Activation:** landing view → signed_up → receipt_completed within 24 h → export_downloaded within 7 days.
2. **Trust:** receipt_completed → field edited (edit rate by field and model). This is your live accuracy metric and decides the model chain.
3. **Monetization:** limit_reached → upgrade_clicked → subscription_started.
4. **Retention:** weeks with ≥1 upload, by sign-up cohort.

## 8. Decisions only the owner can make

1. **Wedge:** freelancers/sole traders (price $9, self-serve) or bookkeepers (price per client, slower sales). Picking one rewrites the landing page.
2. **Plan unit:** does a plan belong to the user or the workspace? Today quota is per user (`core/src/quota.ts`), so a 5-member free workspace gets 5×20/day. Seat pricing depends on this answer.
3. **Price points and free allowance**, including whether free runs on a cheaper model than Pro.
4. **Payment provider** (Stripe vs merchant-of-record like Polar/Paddle for VAT handling) and which countries to sell in.
5. **Model data policy:** is sending receipts to a second provider (Anthropic/OpenAI) acceptable? It needs a privacy-page update and their no-training terms.
6. **Is BYOK still part of the story?** If yes, give a date; if not, drop it from positioning entirely.
7. Whether to publish benchmark results that include competitors.
