# Prompt v2 A/B, 2026-11-07

Extraction prompt v1 (one text block before the file) against v2 (rules in a system prompt, field definitions in
the JSON schema, image before the task; see [docs/architecture/ai.md](../../docs/architecture/ai.md#the-prompt)).
Claude Haiku 5.5 and Gemini 3.5 Flash-Lite, prep `app`, concurrency 1, one run per receipt and prompt. Scores are
field accuracy from `bench/score.ts`, shown as v1 → v2 (difference in points). Only scores are recorded here; the
private sets' images and extracted text stay off the repo.

Sets: the 6 synthetic fixtures, CORD (5), Wikimedia Commons (4), the owner's Nepal receipts (6), web receipts (11)
and AI-generated receipts (5). Spend for the whole A/B, v1 plus two v2 rounds: **$0.27**.

## Result

v2 is the default. On the 31 real receipts it is equal or better on total for both models, and better on every
weak field: dates (Haiku +16, Flash-Lite +6), subtotal (+9, +13), tax (+3, +7), items (+6, +2), merchant (Haiku +4)
and currency (Flash-Lite +6). It costs about 1,700 more input tokens a call on Haiku (+50% per receipt, still
$0.0009) and about 500 more on Flash-Lite (+10%).

- **Dates.** BS-only receipts now come back `null` by design (the keys hold the converted AD date, so they still
  score 0 until the planned code conversion). Haiku reads Nepali month-first dates correctly with the Miti check
  (Nepal 17% → 67%, every remaining miss a BS-only receipt). Flash-Lite applies the rule only some of the time
  (Nepal 17% → 33%) and still sometimes converts a BS-only date itself, wrongly.
- **Subtotal.** The "printed line or null, never a sum of the items" rule removed most of the computed subtotals.
- **Regressions, single receipts:** Flash-Lite put a bakery under Groceries instead of Meals (synthetic set) and,
  on the AI-generated set, kept prices in item names and listed a "Taxes & Fees" line as an item. Haiku lost one
  CORD line split.
- One run per prompt: a single receipt moves a set's score by 9 to 25 points, so read per-set changes with care.
  Round 1 (before the item, discount and date definitions were tightened) moved every weak field the same way.
