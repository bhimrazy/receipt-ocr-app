## Caveats

k6, the app, Postgres and RustFS share one Docker host (8 CPUs), so other work on it lowers the numbers; read the host load column before trusting a failed run. Postgres is local, so there is no cross-region latency; a hosted database adds its round trip time to every sequential query. The fixture model is a timer, not CPU, sockets or tokens, so real extractions use somewhat more.
